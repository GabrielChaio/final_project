# 踩地雷遊戲

一款以 Python + Tkinter 製作的視窗版踩地雷小遊戲，支援多種難度、金屬探測器道具、計時器與操作回放功能。

---

## 環境需求

- Python 3.11
- 套件：`pillow`、`pygame`（詳見 `requirements.txt`）

---

## 安裝與啟動

```bash
# 建立並啟動虛擬環境
conda create -n minesweeper python=3.11
conda activate minesweeper

# 安裝相依套件
pip install -r requirements.txt

# 啟動遊戲
python MinesweeperGameUI.py
```

## 遊戲操作說明

### 主選單

| 按鈕 | 功能 |
|------|------|
| 新遊戲 | 進入難度選擇畫面 |
| 載入遊戲 | 預留功能（尚未實作） |
| 查看排名 | 預留功能（尚未實作） |
| 退出遊戲 | 關閉程式 |

### 難度說明

| 難度 | 地圖大小 | 地雷數量 |
|------|----------|----------|
| 簡單 | 8 × 8 | 8 顆 |
| 普通 | 12 × 12 | 15 顆 |
| 困難 | 16 × 16 | 25 顆 |
| 自訂 | 列 5–27、行 5–44 | 自訂數量（最多為格子總數的 35%） |

### 遊戲設定

開始遊戲前可設定：

- **玩家 ID**：顯示於遊戲畫面上方，預設為 `Unknown`
- **ID 顏色**：自訂玩家名稱的顯示顏色
- **自訂模式**：可另外設定列數（5–27）、行數（5–44）、地雷數量（2 到格子總數的 35%）與金屬探測器使用次數；輸入列數與行數後，地雷數量欄位的範圍標籤會即時更新

### 遊戲規則

1. **左鍵點擊**：翻開該格
   - 第一格點擊必定安全（周圍 3×3 範圍內不含地雷）
   - 翻開數字代表周圍 8 格中的地雷數量
   - 翻開空白格時會自動展開所有相連的空白區域
   - 翻到地雷 → 遊戲結束
   - 已插旗的格子或探測器已標記地雷的格子，左鍵無反應
2. **右鍵點擊**：插旗 / 取消插旗（標記可疑地雷位置）
   - 必須先翻開第一格才能插旗，否則彈出警告視窗
   - 已翻開的格子或探測器已標記地雷的格子，右鍵無反應
3. **勝利條件**：翻開所有非地雷格子

### 金屬探測器道具

遊戲左側面板可選擇探測模式（必須先翻開第一格才能使用）：

| 模式 | 效果 |
|------|------|
| 未使用 | 一般點擊模式 |
| 十字 | 揭示目標格所在的整行與整列 |
| 九宮格 | 揭示目標格周圍 3×3 範圍內所有格子 |

- 探測器使用後地雷格會以黃色背景顯示，安全格直接翻開
- 預設提供 **2 次**使用機會（自訂模式可調整）

### 遊戲結束

- 遊戲結束後可選擇**查看回放**或**返回主選單**
- 回放會以每步 0.5 秒的速度重現整場遊戲操作過程
