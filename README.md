# 踩地雷遊戲

一款以 Python + Tkinter 製作的視窗版踩地雷小遊戲，支援多種難度、金屬探測器道具、計時器與操作回放功能。

---

## 環境需求

- Python 3.11
- 套件：`pillow`、`pygame`（詳見 `requirements.txt`）

---

## 安裝與啟動

```bash
# 建立並啟動虛擬環境
conda create -n minesweeper python=3.11
conda activate minesweeper

# 安裝相依套件
pip install -r requirements.txt

# 啟動遊戲
python MinesweeperGameUI.py
```

## 遊戲操作說明

### 主選單

| 按鈕 | 功能 |
|------|------|
| 新遊戲 | 進入難度選擇畫面 |
| 回放記錄 | 開啟回放記錄視窗 |
| 查看排名 | 開啟排行榜視窗 |
| 退出遊戲 | 關閉程式 |

### 難度說明

| 難度 | 地圖大小 | 地雷數量 |
|------|----------|----------|
| 簡單 | 8 × 8 | 10 顆 |
| 普通 | 12 × 12 | 30 顆 |
| 困難 | 16 × 16 | 60 顆 |
| 自訂 | 列 5–27、行 5–44 | 格子總數的 10%–25% |

### 遊戲設定

開始遊戲前可設定：

- **玩家 ID**：顯示於遊戲畫面上方，預設為 `Unknown`；同一次執行中重複遊玩時，上一局填寫的 ID 與顏色會自動帶入
- **ID 顏色**：自訂玩家名稱的顯示顏色；若選取的顏色感知亮度過高（背景為白色時難以辨識），系統會自動調暗至可讀範圍
- **自訂模式**：可另外設定列數（5–27）、行數（5–44）、地雷數量（格子總數的 10%–25%）與金屬探測器使用次數；輸入列數與行數後，地雷數量欄位的範圍標籤會即時更新

### 遊戲介面

頂部資訊列由左至右顯示：**時間**、**剩餘地雷數量**、**玩家名稱**。

- **剩餘地雷** = 地雷總數 − 探測器揭示的地雷數 − 已插旗格數（可為負數，代表旗子插錯）

### 遊戲規則

1. **左鍵點擊**：翻開該格
   - 第一格點擊必定安全（周圍 3×3 範圍內不含地雷）
   - 翻開數字代表周圍 8 格中的地雷數量
   - 翻開空白格時會自動展開所有相連的空白區域
   - 翻到地雷 → 遊戲結束
   - 已插旗的格子或探測器已標記地雷的格子，左鍵無反應
2. **雙擊左鍵**：自動翻開周圍格子（快速開格）
   - 對已翻開的**數字格**雙擊，若其周圍 8 格中「已插旗格數 + 探測器標記地雷數」恰好等於該數字，則自動翻開剩餘未標記格
   - 若自動翻開的格子中有地雷，一樣會引爆並結束遊戲
3. **右鍵點擊**：插旗 / 取消插旗（標記可疑地雷位置）
   - 必須先翻開第一格才能插旗，否則彈出警告視窗
   - 已翻開的格子或探測器已標記地雷的格子，右鍵無反應
4. **勝利條件**：翻開所有非地雷格子

### 金屬探測器道具

遊戲左側面板可選擇探測模式（必須先翻開第一格才能使用）：

| 模式 | 效果 |
|------|------|
| 未使用 | 一般點擊模式 |
| 十字 | 揭示目標格所在的整行與整列 |
| 九宮格 | 揭示目標格周圍 3×3 範圍內所有格子 |

- 探測器使用後地雷格會以黃色背景顯示，安全格直接翻開
- 預設提供 **2 次**使用機會（自訂模式可調整）

### 遊戲結束

- 遊戲結束後會詢問是否儲存本局回放；選擇儲存後，回放檔案將存入 `Records/` 資料夾
- 若選擇不儲存，直接返回主選單

## 回放記錄

主選單點擊「回放記錄」開啟回放記錄視窗，可瀏覽、播放或刪除先前儲存的回放。

### 回放清單

清單欄位：**玩家**、**難度**、**結果**（勝利 / 失敗）、**耗時**（秒）、**日期**。

| 按鈕 | 功能 |
|------|------|
| 開始回放 | 載入選取的回放並以每步 0.5 秒速度重現整局操作 |
| 刪除 | 刪除選取的回放檔案 |
| 重新整理 | 重新掃描 `Records/` 資料夾並更新清單 |

### 回放說明

- 回放檔案以 JSON 格式儲存於 `Records/replay_YYYYMMDD_HHMMSS.json`
- 回放完整記錄每一步操作（左鍵、右鍵插旗、探測器、雙擊自動翻開）
- 回放期間玩家操作無效，僅能觀看

## 排行榜

主選單點擊「查看排名」開啟排行榜視窗。

### 入榜條件

- 成功通關
- 非自訂模式（僅簡單 / 普通 / 困難）

### 榜單分類

使用兩個下拉選單切換：

**難度**：簡單 / 普通 / 困難

**挑戰類型**：

| 類型 | 條件 |
|------|------|
| 無限制 | 可使用所有功能 |
| 無道具 | 全程未使用金屬探測器 |
| 無道具無旗子 | 全程未使用金屬探測器，且未插旗 |

> 插旗後取消仍算「曾使用旗子」，無法進入無道具無旗子榜。

### 排名規則

- 以完成時間（秒）由小到大排序
- 每榜保留前 10 名
- 同時間者依完成先後排序
- 成績自動儲存於 `leaderboard.json`
