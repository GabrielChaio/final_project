# 踩地雷遊戲

一款以 Python + Tkinter 製作的視窗版踩地雷小遊戲，支援多種難度、金屬探測器道具、計時器、線上排行榜與操作回放功能。

---

## 下載與執行（玩家版）

1. 下載並解壓縮 `踩地雷.zip`
2. 進入解壓後的資料夾，雙擊 `踩地雷.exe` 即可直接遊玩
3. `account.json` 會在首次登入後自動產生於 `踩地雷.exe` 同目錄下

> 無需安裝 Python 或任何相依套件。

---

## 環境需求

- Python 3.11
- 套件：`pillow`、`pygame`、`requests`（詳見 `requirements.txt`）
- 需要網路連線以使用帳號、排行榜與回放雲端同步功能（離線時仍可遊玩）

---

## 安裝與啟動

```bash
# 建立並啟動虛擬環境
conda create -n minesweeper python=3.11
conda activate minesweeper

# 安裝相依套件
pip install -r requirements.txt

# 啟動遊戲
python MinesweeperGameUI.py
```

## 遊戲操作說明

### 主選單

右上角已登入時顯示玩家 ID（底色為 ID 顏色、白色文字）及「登出」按鈕；未登入時顯示「未登入」文字及「登入」按鈕。

| 按鈕 | 未登入時行為 | 已登入時行為 | 離線時行為 |
|------|-------------|-------------|-----------|
| 新遊戲 | 直接進入難度選擇畫面 | 直接進入難度選擇畫面 | 直接進入難度選擇畫面（遊戲結束後無法上傳） |
| 回放記錄 | 彈出登入視窗 | 開啟雲端回放記錄視窗 | 彈出警告，不開啟視窗 |
| 查看排名 | 彈出警告（離線） / 正常開啟（連線） | 彈出警告（離線） / 正常開啟（連線） | 彈出警告，不開啟視窗 |
| 退出遊戲 | 關閉程式 | 關閉程式 | 關閉程式 |
| 登入 | 開啟登入視窗 | — | 開啟登入視窗（登入後仍無法連線） |

#### 登出

點擊「登出」按鈕後，系統彈出確認視窗並再次顯示 Recovery Key（可複製至剪貼簿）。確認後刪除本機 `account.json`，右上角回復為「未登入」狀態。

### 難度說明

| 難度 | 地圖大小 | 地雷數量 |
|------|----------|----------|
| 簡單 | 8 × 8 | 10 顆 |
| 普通 | 12 × 12 | 30 顆 |
| 困難 | 16 × 16 | 60 顆 |
| 自訂 | 列 5–27、行 5–44 | 格子總數的 10%–25% |

點擊「簡單」、「普通」或「困難」後直接進入遊戲（不開啟設定對話框）。點擊「自訂」則開啟設定對話框，可調整列數、行數、地雷數量與探測器次數。

難度選擇頁面右上角僅顯示玩家 ID，不顯示「登出」按鈕（以避免操作混亂）。

### 帳號系統

首次使用「新遊戲」或「回放記錄」時，需先登入帳號。

#### 登入

輸入玩家 ID 與 Recovery Key。

#### 註冊

於登入視窗點擊「點此註冊」，填寫玩家 ID（最多 10 字元）與 ID 顏色後完成註冊。
系統自動產生一組 **Recovery Key**（格式：`XXXX-XXXX-XXXX-XXXX`），**請立即備份**，用於在其他裝置登入。

#### 跨裝置登入

在其他裝置登入時，輸入玩家 ID 與當初備份的 Recovery Key 即可。

#### 注意事項

- 帳號資訊存於同目錄下 `account.json`（含 Recovery Key 明文），請勿公開分享
- 同一裝置第二次啟動時自動使用本機帳號，無需重新登入

### 遊戲設定（僅自訂模式）

選擇「自訂」難度時才會開啟設定對話框，可設定：

- **列數**（5–27）、**行數**（5–44）、**地雷數量**（格子總數的 10%–25%）、**金屬探測器使用次數**（0–99）
- 輸入列數與行數後，地雷數量欄位的範圍標籤會即時更新
- 玩家 ID 與 ID 顏色由登入帳號決定，不在此對話框中設定

### 遊戲介面

頂部資訊列由左至右顯示：**時間**、**剩餘地雷數量**、**玩家名稱**。

- **剩餘地雷** = 地雷總數 − 探測器揭示的地雷數 − 已插旗格數（可為負數，代表旗子插錯）

### 遊戲規則

1. **左鍵點擊**：翻開該格
   - 第一格點擊必定安全（周圍 3×3 範圍內不含地雷）
   - 翻開數字代表周圍 8 格中的地雷數量
   - 翻開空白格時會自動展開所有相連的空白區域
   - 翻到地雷 → 遊戲結束
   - 已插旗的格子或探測器已標記地雷的格子，左鍵無反應
2. **雙擊左鍵**：自動翻開周圍格子（快速開格）
   - 對已翻開的**數字格**雙擊，若其周圍 8 格中「已插旗格數 + 探測器標記地雷數」恰好等於該數字，則自動翻開剩餘未標記格
   - 若自動翻開的格子中有地雷，一樣會引爆並結束遊戲
3. **右鍵點擊**：插旗 / 取消插旗（標記可疑地雷位置）
   - 必須先翻開第一格才能插旗，否則彈出警告視窗
   - 已翻開的格子或探測器已標記地雷的格子，右鍵無反應
4. **勝利條件**：翻開所有非地雷格子

### 金屬探測器道具

遊戲左側面板可選擇探測模式（必須先翻開第一格才能使用）：

| 模式 | 效果 |
|------|------|
| 未使用 | 一般點擊模式 |
| 十字 | 揭示目標格所在的整行與整列 |
| 九宮格 | 揭示目標格周圍 3×3 範圍內所有格子 |

- 探測器使用後地雷格會以黃色背景顯示，安全格直接翻開
- 預設提供 **2 次**使用機會（自訂模式可調整）

### 遊戲結束

遊戲結束後顯示三個按鈕：

| 按鈕 | 條件 | 說明 |
|------|------|------|
| 儲存遊戲紀錄 | 連線（未登入時先登入） | 將本局回放上傳至雲端（`records/{玩家ID}/`）；上傳成功後按鈕變灰，防止重複上傳 |
| 上傳至排行榜 | 連線、勝利且非自訂模式（未登入時先登入） | 將成績與回放一併上傳至排行榜；上傳成功後按鈕變灰 |
| 返回主選單 | 任何狀態 | 直接返回，不儲存任何資料 |

- 未登入時點擊前兩個按鈕，將彈出登入視窗，登入後自動執行上傳；回放 meta 將以登入帳號的玩家 ID 覆寫
- 離線時點擊前兩個按鈕，將顯示「無法連線至伺服器」
- **儲存遊戲紀錄**與**上傳至排行榜**的回放資料各自獨立儲存；刪除個人遊戲紀錄不影響排行榜回放

## 回放記錄

需登入後方可使用，點擊「回放記錄」開啟雲端回放記錄視窗。

### 回放清單

顯示登入玩家在雲端儲存的所有回放，清單欄位：**玩家**、**難度**、**結果**（勝利 / 失敗）、**耗時**（秒）、**日期**。

| 按鈕 | 功能 |
|------|------|
| 開始回放 | 載入選取的回放並進入回放模式 |
| 刪除 | 從雲端刪除選取的回放 |
| 重新整理 | 重新從雲端載入清單 |

### 回放說明

- 回放以 JSON 格式儲存於 Firebase（`records/{玩家ID}/`）
- 每一步操作記錄動作類型、位置與相對時間戳（距首次點擊的秒數，毫秒級精度）
- 回放開啟後直接進入**暫停狀態**，按「繼續」開始播放
- 回放依原始操作間隔播放，長時間思考的停頓也能忠實還原
- 回放期間玩家操作無效，僅能透過控制列操作

### 回放控制列

盤面下方顯示控制列，提供以下功能：

| 元件 | 功能 |
|------|------|
| 繼續 / 暫停 / 返回 | 切換播放狀態；回放結束後顯示「返回」，點擊返回主選單 |
| 速度選單 | 切換播放速度：0.5×、1×（預設）、2×、3× |
| 上一步 | 暫停時回退一步 |
| 下一步 | 暫停時前進一步 |
| 時間軸滑塊 | 可拖移至任意時間點；放開後立即跳至對應步驟 |

## 排行榜

主選單點擊「查看排名」開啟排行榜視窗。

### 入榜條件

- 成功通關
- 非自訂模式（僅簡單 / 普通 / 困難）

### 榜單分類

使用兩個下拉選單切換：

**難度**：簡單 / 普通 / 困難

**挑戰類型**：

| 類型 | 條件 |
|------|------|
| 無限制 | 可使用所有功能 |
| 無道具 | 全程未使用金屬探測器 |
| 無道具無旗子 | 全程未使用金屬探測器，且未插旗 |

> 插旗後取消仍算「曾使用旗子」，無法進入無道具無旗子榜。

### 排名規則

- 以完成時間（毫秒級精度，如 `5.123 秒`）由小到大排序
- 每榜保留前 10 名
- 同時間者依完成先後排序
- 成績儲存於 Firebase 雲端

### 排行榜回放

排行榜視窗底部提供「回放」按鈕，選取任一排名後點擊即可觀看該局遊玩紀錄，**不需登入**。回放資料獨立嵌入排行榜條目，不受個人遊戲紀錄刪除影響。

---

## 離線模式

Firebase 無法連線時：

- 主選單正常顯示（若有本機帳號仍可看到玩家名稱）
- 新遊戲正常進行，但遊戲結束後無法儲存紀錄或上傳排名
- 點擊「查看排名」或「回放記錄」時立即彈出警告視窗，不開啟清單或排行榜
